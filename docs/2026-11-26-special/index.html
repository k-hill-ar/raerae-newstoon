예시 답
① 문제(투수): 오른손 타자도 꼭 상대해야 하는데 케네디는 오른손 타자에게 약해요(피안타율 0.304). → 해결: 오른손 타자 몸쪽으로 들어가는 공을 새로 연습해요. (약점을 줄여야 3명을 다 막을 수 있으니까)
② 문제(감독): 왼손 타자가 1명만 있는 타순에서는 케네디를 내기 애매해요. → 해결: 왼손 타자가 2명 이상 이어지는 타순을 미리 표로 정리해 그때 올려요. (규칙 안에서 강점을 가장 잘 쓰는 순간을 찾으니까)
③ 문제(상대 팀): 상대가 일부러 오른손 대타를 내서 케네디를 괴롭힐 수 있어요. → 해결: 대타가 나올 것까지 생각해 이닝 시작부터 케네디를 맡겨요. (3타자를 채우기 쉬운 이닝 처음이 유리하니까)
④ 규칙 고치기: 규칙을 조금 바꿔 '부상일 때만 예외' 말고 '2아웃 뒤에 나오면 1타자만 상대해도 된다'는 예외를 제안할 수도 있어요. (경기 시간도 줄이고 왼손 전문 투수도 살리니까)

🏅 한 단계 더: 이 규칙은 경기를 빠르게 하려고 생겼어요. 경기가 빨라지는 것과 왼손 전문 투수의 자리를 지키는 것 중 무엇이 더 중요할까요? 이유와 함께 써 보세요. 채점 팁: 많이(유창성), 여러 종류로(융통성), 남과 다르게(독창성), 자세히(정교성) 쓸수록 좋은 답이에요.
