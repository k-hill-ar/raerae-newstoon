📊 역사 속 '수능 한파'

🇰🇷 1998년 11월 18일 영하 5.3도

지금까지 가장 추웠던 수능날이에요.
부산·제주 말고는 모두 영하로 떨어졌어요.

🇰🇷 1993년~지금 4번에 1번꼴

서울 수능날 아침이 영하였던 해는 생각보다 적어요.
옛날 입시는 12월이라 '입시 한파'란 말이 생겼어요.

👉 기억할 것: 수능 한파는 늘 오는 게 아니라 가끔 오는 손님이에요. 올해가 6년 만!

❓ 오늘의 퀴즈

4학년올해 수능날(19일) 아침, 서울 기온은 몇 도로 예보됐을까요?① 영상 10도 ② 영하 1도 ③ 영하 15도 — 눌러서 정답 확인
정답은 ② 영하 1도! 서울 수능날 아침이 영하로 떨어지는 건 2020년 이후 6년 만이에요.
6학년수능날이 실제로는 4번에 1번꼴로만 영하였는데, 왜 '입시는 춥다'는 말이 생겼을까요?눌러서 정답 확인
수능이 생기기 전에는 입시가 11월 말~12월, 1월에 몰려 있었고 난방도 부족했어요. 추운 때 시험을 보던 기억이 '입시 한파'라는 말로 남은 거예요.
🧠 창의 도전영하로 추운 시험날, 수험생이 집에서 시험장까지 가는 길과 시험장 안에서 겪을 수 있는 문제 3가지 이상을 찾아보세요. 그리고 문제마다 해결할 물건이나 규칙을 새로 설계해 보세요.정답은 여러 개! 생각해 본 뒤 눌러 보세요
생각 길잡이: 수험생이 되어 아침에 눈을 떠서 시험이 끝날 때까지를 시간 순서대로 머릿속으로 따라가 보세요. "이때 추위 때문에 뭐가 불편할까?"를 장면마다 묻고, 찾은 문제마다 "누가, 무엇을 바꾸면 해결될까?"를 생각해요.

예시 답
① 문제: 길이 미끄러워 늦을 수 있다 → 규칙: 시험장 근처 길에 전날 밤 미리 제설제를 뿌리고, 수험생 차는 먼저 지나가게 해요. 늦으면 시험을 못 보니, 가장 큰 위험부터 막는 거예요.
② 문제: 손이 곱아 글씨가 잘 안 써진다 → 물건: 손가락 끝만 뚫린 '시험용 장갑'을 만들어요. 손등은 따뜻하고 손가락은 자유로우니 마킹도 잘 할 수 있어요.
③ 문제: 교실이 춥거나, 난방 때문에 너무 덥거나 건조하다 → 물건: 겹겹이 입고 벗기 쉬운 '지퍼 조끼'를 입게 해요. 얇은 옷 여러 겹은 사이사이 공기가 갇혀 따뜻하고, 더우면 하나만 벗으면 되니까요.
④ 문제: 쉬는 시간에 찬 음식을 먹으면 배가 아플 수 있다 → 규칙: 시험장마다 따뜻한 물을 받을 수 있는 정수기 자리를 정해 두어요. 몸 속부터 데우면 집중이 잘 되니까요.

🏅 한 단계 더: 내가 만든 해결책 때문에 새로 생기는 문제는 없을까요? 예를 들어 손가락 장갑 속에 글씨를 써 넣는 부정행위가 걱정된다면, 규칙을 어떻게 고쳐야 할까요? 채점 팁: 많이(유창성), 여러 종류로(융통성), 남과 다르게(독창성), 자세히(정교성) 쓸수록 좋은 답이에요.
