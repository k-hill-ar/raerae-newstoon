예시 답
① 쓰는 기간: 오래 두는 것(공책, 창호지) / 한 번 쓰고 버리는 것(휴지, 영수증, 종이컵) / 그 사이(신문, 택배 상자, 색종이) — 한지처럼 오래가야 하는 종이가 무엇인지 알 수 있어서.
② 물과의 관계: 물을 빨아들여야 하는 것(휴지) / 물을 막아야 하는 것(종이컵) / 물에 약하면 곤란한 것(나머지) — 종이마다 만드는 법이 다른 이유를 알 수 있어서.
③ 글자를 담나?: 글·그림을 담는 것(공책, 신문, 영수증, 색종이) / 물건을 담거나 막는 것(택배 상자, 종이컵, 창호지, 휴지).
④ 다시 쓸 수 있나?: 재활용 잘 되는 것 / 어려운 것 — 환경을 생각하는 기준이라서.
