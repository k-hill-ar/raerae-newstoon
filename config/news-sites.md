# 클라우드에서 열 수 있게 허용한 뉴스 사이트

클라우드 환경(Default) > Network access > Custom > Allowed domains 에 넣은 목록입니다.
후보의 출처 링크는 **이 목록에 있는 사이트 주소를 우선** 씁니다. 목록 밖의 사이트는 클라우드에서 열리지 않습니다.

※ 네이버(naver.com)는 Claude의 웹 검색·웹 읽기 도구 접근을 사이트 쪽에서 막고 있어서 출처로 쓸 수 없습니다.
