# 래래 뉴스툰 영재원 특별편 제작 규칙

`config/rules.md`(등장인물, 문체, 금지 사항, 출처 확인)를 **그대로 따르고**, 아래 내용을 더한다.

## 1. 목적과 독자
- 라이언(4학년)의 **강동송파교육지원청 영재교육원 과학 분야** 선발 시험 대비. 시험일 **2026년 12월 5일(토)**.
- 과학 분야 시험은 **창의적 문제해결력**과 **창의인성 서·논술** 두 가지다.
- 교육청 선발에 쓰이는 KEDI 검사는 학년 교육과정 수준 안에서 실생활 문제로 사고력을 본다. 그래서 **3~4학년 과학 개념**을 바탕으로, 처음 보는 상황에 적용하는 문제를 만든다. 더 깊은 원리는 "한 걸음 더"에서만 짧게 소개한다.
- 뉴스가 아니므로 **12회차를 미리 모두 만들어 두었다.** 매일 예약 작업으로 만들지 않는다.

## 2. 날짜 잠금
- 각 회차는 **한국 시간 그 날짜 0시**에 자동으로 열린다. 그 전에는 잠금 화면(D-day, 남은 시간)이 보인다.
- 부모님 비밀번호를 넣으면 미리 볼 수 있다. 브라우저 창을 닫으면 다시 잠긴다(sessionStorage).
- 비밀번호 원문은 저장소에 두지 않는다. `docs/assets/gifted.js`의 `GIFTED_PW_HASH`에 SHA-256 값만 둔다.
  - 바꾸는 법: `python3 -c "import hashlib;print(hashlib.sha256('새비밀번호'.encode()).hexdigest())"` 결과로 교체.
- 본문과 만화 대본은 페이지 안에 base64로 들어 있어 화면에는 안 보이지만, 공개 저장소이므로 진짜 보안은 아니다(아이가 미리 보지 않게 하는 정도).

## 3. 파일 구조
```
gifted-src/episodes.json   회차 정보(번호, 날짜, 분야, 잠금 화면 주제, 제목, 부제, 영재원 연결 문장)
gifted-src/NN.html         본문(정리, 역사, 도감, 교과 연결, 한 걸음 더, 퀴즈, 코칭 노트, 출처)
gifted-src/NN.js           만화 대본(PANELS) + 그 회차 전용 소품
scripts/build_gifted.py    위 파일로 docs/gifted/NN/index.html, meta.json, 모아보기를 만든다
docs/assets/gifted.css/js  영재원편 공용 스타일·소품·애니메이션·날짜 잠금
```
- **고칠 때는 `gifted-src/`를 고치고 `python3 scripts/build_gifted.py`를 실행**한다. `docs/gifted/`를 손으로 고치지 않는다.
- 공용 `newstoon.css`, `newstoon.js`는 고치지 않는다.

## 5. 페이지 구성
1. 머리(빌드 스크립트가 만듦): 태그, D-day, 제목, 부제, 영재원 연결 상자
2. **애니메이션 만화 8컷**(12화는 4컷): 도입 → 피카 등장 → 핵심 원리 → 야구 비유 → 역사 2컷 → 놀라운 포인트 → 마무리(D-day 응원)
3. 📰 정리 3줄 · 📊 역사(연표 3칸 + 카드 2개, 출처 2곳 확인) · 📖 도감 `No.G##` · 🔗 교과 연결 · 🔭 한 걸음 더(계산)
4. ❓ 퀴즈: `lv4` 4학년, `lv6` 6학년, `lvC` 🧠 창의 도전, `lvS` 🧪 실험 설계, `lvE` ✍️ 창의인성 서·논술
5. 👨‍👩‍👦 부모님 코칭 노트, 출처 (저장하기 칸은 빌드 스크립트가 넣음)

## 6. 만화 움직임
- 인물 `bob(...)`, 피카 `hop(...)`, 원리 그림 `class="grow g1~g6"`(차례로 커짐) 또는 `draw`(선 그리기, `pathLength="1"`).
- 그 밖에 `pulse`, `float`, `wiggle`, `shake`, `wave`, `zz`, `spin`, `twinkle`, `snowfall()`.
- 말풍선 25자 안쪽, 얼굴과 그림 글자를 가리지 않게.

## 7. 하지 말 것
- 아이 혼자 하면 위험한 실험을 답이나 활동으로 쓰지 않는다.
- 학원 이름, 실제 기출 문제를 그대로 옮기지 않는다.
- 실제 아이 이름·사진·학교, 실제 포켓몬 이름·그림을 넣지 않는다.
