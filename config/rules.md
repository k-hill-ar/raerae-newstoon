# 래래 뉴스툰 제작 규칙

자동화할 때 Claude에게 그대로 넘겨줄 지시문입니다. 시제품을 보고 수정하면 다음 날부터 반영됩니다.

## 1. 독자
- 초등 6학년, 4학년 형제
- 둘 다 야구를 매우 좋아함. 동생(4학년)은 포켓몬스터를 좋아함
- 글은 **4학년 기준**으로 쓰고, 6학년용 "한 걸음 더" 코너를 따로 둔다

## 2. 뉴스 선별 기준 (매일 5개)
- **우선:** 과학, 우주, 환경, 동물, 스포츠(특히 야구), 경제 기초, 세계 문화, 계절과 절기, 가족이 함께 할 수 있는 일
- **제외:** 범죄, 사고 사망, 자살, 선정적 내용, 참혹한 전쟁, 정치 공방, 확인되지 않은 소문
- 5개 중 최소 1개는 야구나 스포츠, 최소 1개는 과학이나 우주
- 날짜와 숫자는 **출처 2곳 이상에서 확인**한 것만 쓴다. 확인 안 되면 후보에서 뺀다

## 3. 등장인물 (고정)
| 이름 | 설정 | 생김새 |
|---|---|---|
| 준 | 형, 6학년, 투수. 차분하고 아는 게 많다 | 파란 야구모자(앞에 "6"), 파란 줄무늬 유니폼 |
| 율 | 동생, 4학년, 타자. 호기심 폭발, 몬스터 도감 수집가 | 빨간 야구모자(앞에 "4"), 빨간 유니폼, 큰 눈 |
| 꼬미 (가칭) | 형제를 따라다니는 오리지널 꼬마 몬스터. 뉴스 해설 담당 | 노란 동그란 몸, 번개 모양 더듬이 1개, 둥근 귀 |

- 꼬미의 이름은 동생이 새로 지어주면 바꾼다
- **실제 포켓몬 캐릭터 그림과 이름은 쓰지 않는다** (저작권). 대신 "타입", "도감 번호", "진화" 같은 개념을 설명 도구로 쓴다
- 실제 아이들의 이름, 사진, 학교는 절대 넣지 않는다 (공개 웹페이지)

## 4. 만화 구성 (학습만화체)
1. 제목 + 날짜 + 분야 태그
2. **6컷 만화**: 상황 도입 → 꼬미 등장 → 핵심 사실 → 야구 비유 → 놀라운 포인트 → 마무리
3. **뉴스 정리**: 사실 3줄 (만화 속 과장 없이)
4. **뉴스 도감**: 오늘의 핵심 단어 1~2개를 도감 카드로. 번호는 매일 하나씩 올라간다
5. **한 걸음 더 (6학년)**: 계산이나 원리 하나
6. **오늘의 퀴즈**: 4학년용 1문제, 6학년용 1문제. 누르면 정답이 나온다
7. 출처 링크

## 5. 문체
- 대사는 짧게, 한 말풍선에 25자 안쪽
- 숫자는 아이가 체감할 수 있는 것과 비교한다 (야구공 속도, 야구장 크기, 학교 운동장 등)
- 과장된 효과음과 감탄은 만화 컷 안에서만 쓰고, 정리 코너는 정확하게
